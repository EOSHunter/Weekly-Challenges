# R7 repository context: Weekly Challenges

This repository contains four independent Create React App exercises in `veryeasy/`, `easy/`, `medium/`, and `hard/`. Each has its own `package.json`, `public/`, and `src/` directory. They are small practice examples, not one integrated app.

At the checked-in `master` revision, `veryeasy/src/App.js` renders a Hello World heading; `easy/src/App.js` renders a greeting through a local `Header` component; `medium/src/App.js` renders a contact sentence using props. `hard/src/App.js` attempts to map contact data into a list, but its references to `this.contact` and `contactsArray` do not match its local variables, so do not describe that exercise as working.

This describes `master` at `fb8d6cc48e2e9d6a5a64d8347aba97c93958d36a`. See [2017 changes](changes/2017-09.md) and [decisions](decisions.md). Runtime behavior has not been tested.
